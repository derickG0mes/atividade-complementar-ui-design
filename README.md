# 🎨 UI Design para Iniciantes — Origamid
Repositório dedicado aos estudos, exercícios práticos e projetos desenvolvidos durante o curso **UI Design para Iniciantes** oferecido pela [Origamid](https://www.origamid.com).

## Sobre o Curso
O curso abrange os conceitos fundamentais do design de interfaces de usuário (UI) e da experiência do usuário (UX), guiando desde a teoria da tipografia e teoria das cores até a prototipação de alta fidelidade e criação de *Design Systems* no Figma.

* **Carga Horária:** 34 horas
* **Período:** 13/01/2026 a 21/04/2026
* **Status:** Concluído ✅

## Principais Aprendizados
* **Fundamentos de UI/UX:** Hierarquia visual, espaçamento, alinhamento, consistência e heurísticas de usabilidade.
* **Tipografia & Cores:** Escolha tipográfica, variáveis, teoria das cores, contraste acessível e criação de paletas funcionais.
* **Layouts Responsivos & Grids:** Estruturação de páginas adaptáveis para desktop e mobile.
* **Prototipação no Figma:** Uso de componentes, variantes, auto layout e interações dinâmicas.
* **Design System & Componentização:** Padronização de guias de estilo, botões, formulários e elementos navegáveis.
* **Projeto Final (Bikcraft):** Criação completa do layout, wireframes, guia de estilos e protótipo interativo.

## Ferramentas Utilizadas
* **Figma** (Prototipação, Wireframes e UI Kits)
* **HTML5 / CSS3** (Visão técnica de implementação front-end)
